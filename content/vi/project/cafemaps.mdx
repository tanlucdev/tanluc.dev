### Về Dự Án

**Cafe Maps** là một sản phẩm full-stack giúp người dùng tìm quán cà phê phù hợp tại TP.HCM: không chỉ theo tên hay quận, mà theo đúng ngữ cảnh sử dụng như làm việc, học tập, hẹn hò, gặp bạn bè, chill một mình hoặc cần một không gian yên tĩnh.

Dự án được xây dựng như một hệ sinh thái hoàn chỉnh gồm website người dùng, REST API backend và CMS nội bộ. Trọng tâm của sản phẩm là trải nghiệm tìm kiếm nhanh, dữ liệu quán được biên tập kỹ, khả năng định vị gần tôi bằng PostGIS/OSRM và quy trình quản trị đủ tốt để vận hành nội dung lâu dài.

### Tech Stack

- **Frontend:** Next.js App Router, React 19, TypeScript, next-intl, TanStack Query, Framer Motion, Lenis, Tailwind CSS, shadcn/Base UI, lucide-react.
- **Backend:** NestJS, REST API, Prisma ORM, PostgreSQL, PostGIS, JWT, bcrypt, class-validator, Swagger, compression.
- **CMS/Admin:** Vite, React, React Router, TanStack Query, TanStack Table, React Hook Form, Zod, Zustand, Radix UI, Tailwind CSS.
- **Storage & Media:** Supabase Storage, Sharp, WebP conversion, HEIC/HEIF fallback conversion, remote image import with URL safety checks.
- **Maps & Location:** PostGIS geography queries, OSRM route distance, Google Maps deep links.
- **Infra:** Vercel for frontend/CMS, Render-ready backend, environment-based CORS, API cache headers and graceful fallback data.

### Kiến Trúc Tổng Quan

Cafe Maps được tách thành ba lớp rõ ràng:

- **Frontend public site** xử lý trải nghiệm khám phá, search, SEO, i18n, detail page, saved cafes, blog và contribution flow.
- **Backend API** chịu trách nhiệm chuẩn hóa dữ liệu, phân trang, lọc, auth, geospatial search, upload ảnh, quản lý submissions và nội dung blog.
- **CMS** cung cấp giao diện vận hành cho admin: dashboard, CRUD quán, CRUD blog, quản lý user, duyệt đóng góp, publish/unpublish và featured ordering.

Cách tách này giúp phần trải nghiệm người dùng luôn nhẹ và cache tốt, trong khi các tác vụ nặng như xử lý ảnh, kiểm duyệt, role admin và truy vấn địa lý được gom vào backend.

### Technical Implementation

#### Search, Filter & Geospatial Query

Backend dùng Prisma để build filter theo search, quận, vibe, purpose, khoảng giá, trạng thái mở cửa và sort mode. Với tính năng gần tôi, API dùng PostGIS `ST_DWithin` và `ST_Distance` để tìm quán trong bán kính, sau đó có thể gọi OSRM Table API để trả về khoảng cách lái xe thực tế.

Nếu OSRM timeout, rate limit hoặc chưa được cấu hình, hệ thống tự fallback về khoảng cách đường chim bay thay vì làm hỏng trải nghiệm người dùng.

```txt
GET /api/cafes/nearby?lat={lat}&lng={lng}&radius={radiusKm}&distanceMode=route
```

#### Localized Content Pipeline

Dữ liệu quán và blog có trường tiếng Việt/tiếng Anh riêng. Backend có mapper chuẩn hóa theo `locale`, frontend gửi locale vào query và render route `/vi` hoặc `/en` bằng `next-intl`. Cách này giữ API rõ ràng, tránh duplicate page logic và vẫn đảm bảo SEO cho từng ngôn ngữ.

#### CMS Workflow

CMS được thiết kế cho vận hành thật: admin có thể tạo/sửa quán theo tab, upload ảnh, import ảnh từ URL, đổi thứ tự gallery, chọn cover/menu image, bật/tắt publish, đánh dấu featured và duyệt submissions thành draft cafe. Blog editor hỗ trợ nội dung song ngữ, markdown toolbar, preview, tag, checklist, lịch đăng và trạng thái featured.

#### Media Processing

Upload ảnh đi qua backend để chuyển sang WebP bằng Sharp, giới hạn dung lượng, hỗ trợ HEIC/HEIF fallback và lưu lên Supabase Storage. Với import ảnh từ URL, backend kiểm tra protocol, credentials, redirect và private IP để giảm rủi ro SSRF trước khi tải ảnh.
